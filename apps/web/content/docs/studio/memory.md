---
title: Memory
description: Short, standing facts about how your business works that the agent carries into every conversation.
---

**Studio → Memory** holds facts about how your business works that no document states: "We never book installs on Fridays." "The owner handles complaints himself." The agent carries every memory into every conversation, by voice, by chat, in Ask and in automations.

## Memory, knowledge or business profile?

| Use | For | How the agent gets it |
| --- | --- | --- |
| [Business profile](/docs/studio/identity#business-profile) | Name, address, website, a one-paragraph description. | In every conversation. |
| **Memory** | Short rules and exceptions a new hire is told on day one. | In every conversation. |
| [Knowledge](/docs/studio/knowledge) | Longer material: price lists, policies, service areas. | Searched only when needed. |

Because every memory is read in every conversation, keep memories short. Move anything long into Knowledge.

Memory is about the business, not about one customer. What a customer said lives on their contact in Desk; the Memory page links to the contacts that have history. See [Contacts](/docs/desk/contacts).

## Add a memory

1. Open **Studio → Memory** and press **Add a memory**.
2. Enter a **Title**, for example "Scheduling rules".
3. Under **What to remember**, write the fact the way you would tell a new hire, for example: "We never book installs on Fridays. If a caller insists, offer the Thursday before or the Monday after."
4. Press **Save** (or Ctrl+Enter).

The agent uses it from the next conversation. A memory can be up to 20,000 characters, but a few sentences is best.

## Edit or forget a memory

Click a memory card to open it. Change the text and press **Save**, or press **Forget** to delete it. The agent stops knowing it from the next conversation. The title cannot be changed after the memory is created; to rename it, add a new memory and forget the old one.

Use **Search memory** to find a note by its title or text, and sort by **Recently edited** or **A–Z**.

## The agent adds memories too

The agent has a tool to save a memory when it learns a lasting fact about how the business works. Its instructions say to use it for facts future calls should know, not for details about one customer. If the agent saves a memory with a title that already exists, it replaces that memory's text.

Memories the agent saves appear on the Memory page like any other, so you can read, correct or forget them. Check the page from time to time.

> [!TIP]
> Treat memory as a short list of rules you would pin next to the phone. If a memory grows into a page, move it into a Knowledge document.

Memories also appear in the **Knowledge** library, labelled **Agent memory**.

## How the agent uses memory

Memories are part of the business information the agent is given at the start of each conversation, next to your business profile. The agent treats this information as accurate, so it may state a fact from memory to a customer. Write memories as facts you are happy for customers to hear.
